## 🎯 Why This Repository Exists

I'm a strong believer in **learning by building**.

Not everything here is production-ready, and that's intentional.

Some folders contain small experiments, some contain exercises, and others contain things I built while learning a particular concept.

The goal is to keep track of my progress and have a place to experiment without worrying about everything being perfect.
